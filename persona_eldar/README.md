# Persona: цифровая копия Эльдара Богунова (Qwen2.5-3B)

Полный SFT-файнтюн общей базы `Qwen2.5-3B-Instruct/` на текстах телеграм-канала
«Творчество Эльдара Богунова» (2023–2026). Модель **полностью независима** от
медицинских (`med-dialogue-3b`, `med-cot-3b`) — отдельные данные, отдельный вес.

## Данные

| Файл | Что это |
|---|---|
| `data/eldar_train_v3.jsonl` | **текущий** датасет (1860): монологи с переложенными вопросами (1518) + фактовые QA (52) + якоря ×2 (70) + потоковые склейки (220) |
| `data/eldar_val_v3.jsonl` | 40 примеров для val loss |
| `data/eldar_train_v2.jsonl`, `data/eldar_train.jsonl` | предыдущие версии (v2: якоря без перекладки; v1: исходная) |
| `data/system_prompt.txt` | карточка персоны v3 (identity + «факты не выдумывай» + поток через темы + пунктуация оригинала) |
| `data/system_style.txt` | инференс-надстройка: ответ сначала, потом соскоки по темам |
| `make_train_v2.py` | генерирует v2 из v1: якоря + замена системного промпта |
| `make_train_v3.py` | генерирует v3: перекладка вопросов + факты + якоря + потоковые склейки |

Зачем v3: в v2 пары «вопрос → монолог» не были связаны по смыслу — модель
выучила «выдавай поток в стиле на любой вопрос», отсюда бред и уход от темы.
В v3 каждый монолог получает вопрос, на который он реально отвечает, по 2
формулировки. Фактовые QA дают якоря против галлюцинаций. Потоковые склейки —
ответы из фрагментов 9 разных тем подлинных постов: учат длинный ответ,
прыгающий между темами, как у оригинала. Пунктуация приведена к статистике
оригинала (замер по корпусу): каждая строка с заглавной, запятые, почти без
точек — 96% строк с заглавной, 28,9 запятых и 6,3 точки на 1000 знаков
(у оригинала 95% / 29,1 / 6,3).

Чистка корпуса (пересборка 2026-08-27): из текстов персоны вырезаны ссылки,
номера карт, никнеймы (eldar86 и т.п.); рекламные посты (рефералки Тинькофф,
VPN) удалены целиком — 771 → 759 текстов. Оригиналы с полными метаданными
хранятся в `messages_all.jsonl` датасета-источника.

Зачем v2: на v1 модель выучила стиль, но не представлялась (в данных не было
вопросов «кто ты?») и на любой вопрос выдавала бесконечный монолог (все примеры
длинные). Якоря: представление (составлено из реальных самоописаний Эльдара
в корпусе), приветствия, короткие ответы по темам — длина ответа теперь зависит
от вопроса. Монологи остаются основой — стиль не тронут.

Источник — канал вёл админ, поэтому в датасет отобраны только тексты, атрибутированные
самому Эльдару: посты с его подписью, пересылки с его личных аккаунтов и неподписанные
монологи от первого лица (итог: 771 уникальный текст, ~606 тыс. символов, дедупликация).
User-реплики синтетические — детерминированные вопросы по теме поста (съёмки/деньги/
быт/люди/идеи). Полная предыстория и пайплайн пересборки:
`~/.zcode/workspace/default/eldar_dataset/` (README.md там же).

Стиль сохранён намеренно: строчные буквы, авторская орфография («мани», «сьемки»),
почти без знаков препинания — копия должна писать как оригинал, данные не нормализовать.

## Гиперпараметры (в `train_eldar.py`, preset один)

- `max_len 1536` — медиана примера 543 токена, p95 1235; обрезается 8 примеров из 733
- `epochs 3.0` — выборка маленькая (~140 оптимизационных шагов), стилю нужно больше проходов
- `batch 1 × accum 16`, `lr 2e-5`, cosine, warmup 3%, bf16, gradient checkpointing,
  adamw_bnb_8bit — та же связка, что у медицинских пресетов, влезает в 24 ГБ
- чекпоинты: `runs/eldar-persona-3b/` (раз в 50 шагов), итог: `models/eldar-persona-3b/`

## Команды (из корня проекта)

```bash
cd /home/sgv/Desktop/Dev/AI_Dev/AI_Dev_Qwen2.5-3B_Diagnosis-training

# 0. Самотест движка обучения (~2 мин; ждать "ENGINE OK")
.venv/bin/python scripts/check_engine.py

# 1. Обучение (~25–45 мин на RTX 3090; журнал — в runs/train_eldar.log)
PYTHONUNBUFFERED=1 .venv/bin/python persona_eldar/train_eldar.py 2>&1 | tee runs/train_eldar.log
#    Признак успеха — строка "ГОТОВО: полная модель сохранена в models/eldar-persona-3b"
#    После обрыва: та же команда с --resume — продолжит с последнего чекпоинта.

# 2. Оценка: val loss + генерации на контрольные вопросы (~3 мин)
.venv/bin/python persona_eldar/evaluate_eldar.py --model models/eldar-persona-3b

# 3. Интерактивный чт с копией
.venv/bin/python persona_eldar/chat_eldar.py --model models/eldar-persona-3b --max-new 800

# 3b. RAG-чат — два режима:
#     montage (по умолчанию): ответ собирается из подлинных строк — 2 строки
#       тематического поста + 9 случайных фраз разных тем; стиль и факты 100%,
#       отвечает мгновенно, деградация невозможна;
#     generate: модель сама пересказывает монтаж своими словами (живее, но
#       3B обрабатывает список «вольно» и может уйти в свои аттракторы).
.venv/bin/python persona_eldar/chat_eldar_rag.py --mode montage
.venv/bin/python persona_eldar/chat_eldar_rag.py --mode generate
.venv/bin/python persona_eldar/chat_eldar_rag.py --show-sources   # показывать найденные посты
```

Мониторинг: `watch -n 5 nvidia-smi`, `tail -f runs/train_eldar.log`.

### Аварийные ручки

- OOM на шаге после валидации (буфер ло́гитов 151936×seq в fused CE-лоссе unsloth):
  скрипт уже выставляет `PYTORCH_CUDA_ALLOC_CONF=expandable_segments:True` и
  `UNSLOTH_CE_LOSS_N_CHUNKS=4` (режет буфер на 4 части). Если всё равно OOM —
  `--max-len 1024` (обрежется ~14% примеров — хвосты длинных монологов).
- Unsloth не прошёл самотест: `--engine transformers` (медленнее, но то же качество).
- Переобучение (val loss растёт после 2-й эпохи): `--epochs 2` и взять лучший чекпоинт.

## Отличия от медицинских моделей

- одна модель вместо двух (нет конвейера), промпты — разговорные, не медицинские;
- оценка без бенчмарка фактов: для персоны главный критерий — узнаваемость стиля
  (evaluate_eldar.py показывает генерации глазами, val loss — вспомогательно);
- чат держит последние 8 реплик + системный промпт — копия «помнит» диалог в рамках сессии.

## Заметки

- В текстах остались донат-реквизиты, которые автор публиковал сам; при публичном
  деплое решите, должна ли копия их воспроизводить.
- Модель воспроизводит манеру и лексику конкретного человека — использовать
  с указанием, что это пародийная ИИ-копия, не сам автор.
